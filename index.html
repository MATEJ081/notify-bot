Features

🛡️ Guardrail

Rate limit a 5 messaggi/minuto, deduplicazione automatica, e DRY_RUN mode di default. Nessun rischio di invii accidentali.

🌐 Tailscale

Accessibile solo dalla tua rete privata Tailscale. Zero esposizione a internet pubblico.

🔐 Autenticazione

Bearer token authentication. Il server non fa mai polling o riceve comandi. Solo outbound.

📊 Logging Sicuro

Log non contengono mai token, chat ID, o testo completo. Solo event tracking.

🚀 MCP Protocol

Standard Model Context Protocol. Funziona direttamente con Claude Code e altri client MCP.

📦 Deploy

Systemd service, Docker container, o Docker Compose. Setup automatico via bash script.
